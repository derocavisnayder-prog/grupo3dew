Consejos para resolver una Ecuación Lineal:

  1. Resolver primero los paréntesis en ambos miembros y agrupar términos.
  2. Eliminar denominadores.
  3. Agrupar los términos con incógnitas a un lado de la ecuación y los términos sin incógnita al otro.
  4. Despejar la incógnita.

Por favor, recuerda que siempre puedes comprobar el resultado sustituyendo la solución en la ecuación y comprobando que se cumpla la igualdad.

Ejercicios Resueltos Paso a Paso

Revisa los siguientes casos prácticos para entender cómo se aplica el despeje algebraico:

Ejemplo 1: Ecuación básica

Resolver: 3x + 5 = 20

Paso 1: Pasamos el +5 al otro lado restando → 3x = 20 - 5

Paso 2: Operamos → 3x = 15

Paso 3: El 3 pasa dividiendo → x = 15 / 3

Resultado: x = 5

Ejemplo 2: Con términos negativos

Resolver: 5x - 8 = 2

Paso 1: Pasamos el -8 sumando → 5x = 2 + 8

Paso 2: Operamos → 5x = 10

Paso 3: Despejamos x → x = 10 / 5

Resultado: x = 2

Ejemplo 3:

Resolver: 5x + 4 = 1 - x

Paso 1: Pasamos el +4 restando y -x sumando → 5x + x = 1 - 4

Paso 2: Operamos → 6x = -3

Paso 3: Despejamos x → x = -3 / 6

Resultado: x = -0.5

Ejemplo 4:

Resolver: 3.(x - 5) = 6

Paso 1: multiplicamos el 3 dentro del paréntesis → 3x - 15 = 6

Paso 2: Pasamos el -15 sumando → 3x = 6 + 15

Paso 3: Operamos → 3x = 21

Paso 4: Despejamos x → x = 21 / 3

Resultado: x = 7

Ejemplo 5:

Resolver: 4.(2x + 1) = x + 4

Paso 1: multiplicamos el 4 dentro del paréntesis → 8x + 4 = x + 4

Paso 2: Pasamos el +4 restando y +x restando → 8x - x = 4 - 4

Paso 3: Operamos → 7x = 0

Paso 4: Despejamos x → x = 0 / 7

Resultado: x = 0

Ejemplo 6:

Resolver: 3 - x = 3.(x + 5)

Paso 1: multiplicamos el 3 dentro del paréntesis → 3 - x = 3x + 15

Paso 2: Pasamos el +3 restando y el +3x restando → -x - 3x = 15 - 3

Paso 3: Operamos → -4x = 12

Paso 4: El -4 pasa dividiendo → x = 12 / -4

Resultado: x = -3

Ahora, practica lo aprendido:

Ejemplo 7: -3x + 5x/9 = 4/3 - 2x

Ejemplo 8: 3.(-2x + 5)/2 = 1 + 4x

Ejemplo 9: 2.(x - 4)/3 = 4.(2x - 1)/15

Ejemplo 10: (2x - 5)/4 + 1 = x + 3/4

Ejemplo 11: (x - 7)/7 + 25.(x - 2)/3 = (5x + 35)/4 + 5/2.(x - 7)

Ejemplo 12: (1 - x)/25 - x/6 + (x + 7)/9 = 2/5 - 3x/15
